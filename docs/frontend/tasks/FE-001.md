```text
Vue 3
Vite
TypeScript（strict）
Nuxt UI v4
Tailwind CSS v4

Pinia
```

## 范围（In Scope）

创建并配置：

```text
Vue 3
Vite
TypeScript（strict）
pnpm（package.json 固定 packageManager 字段）
Nuxt UI v4（官方 Vue 集成：@nuxt/ui/vite 插件 + @nuxt/ui/vue-plugin）
Tailwind CSS v4
Vue Router
Pinia
ESLint（flat config）
Vitest 基线
```

创建最小文件：

```text
App.vue
main.ts
router（index.ts / routes.ts / guards.ts 骨架）
home placeholder route
全局样式表（@import "tailwindcss"; @import "@nuxt/ui";）
```

按 FrontendArchitecture.md 的目标结构创建目录骨架：

```text
frontend/
├── public/
├── src/
│   ├── app/           (App.vue, main.ts)
│   ├── router/
│   ├── layouts/
│   ├── pages/         (home 占位)
│   ├── features/
│   ├── shared/
│   │   └── styles/    (main.css)
│   ├── stores/
│   └── mocks/
│       └── fixtures/
├── tests/
│   └── unit/          (Vitest 基线)
├── .env.example
├── .gitignore
├── eslint.config.*
├── package.json
├── pnpm-lock.yaml
├── tsconfig.json
└── vite.config.ts
```

创建脚本：

```text
dev
build
lint
typecheck
test
check（聚合 lint + typecheck + test + build）
```

配置要求：

- Vite alias：`@ -> src`
- Nuxt UI Vite 插件：`ui()`（来自 `@nuxt/ui/vite`）
- Nuxt UI 应用插件：`app.use(ui)`（来自 `@nuxt/ui/vue-plugin`）
- TypeScript strict 开启
- `.env.example` 含 `VITE_API_BASE_URL=/api`
- `.gitignore` 忽略 node_modules、dist、auto-imports.d.ts、components.d.ts 等生成文件

## 推荐实施步骤

1. 检查环境：`node -v`（目标 Node.js 22 LTS）、`pnpm -v`；确认没有旧 `frontend/` 残留。
2. 在 `frontend/` 下初始化 Vue 3 + Vite + TypeScript 项目（官方脚手架，或手动搭建等价结构）。
3. 安装依赖：
   - 运行时：`@nuxt/ui`、`tailwindcss`、`vue-router`、`pinia`
   - 开发：`eslint`、`vitest`、`@vue/test-utils` 及 Vue/TS 相关插件
   - 禁止：第二套 UI 库（Element Plus / Ant Design Vue / PrimeVue / Arco / Vuetify）、axios、Motion、GSAP、Anime.js
4. 配置 `vite.config.ts`：`vue()` + `ui()`（`@nuxt/ui/vite`）、`resolve.alias` 中 `@ -> ./src`。
5. 配置 `main.ts`：`createApp` + `router` + `pinia` + `ui`（`@nuxt/ui/vue-plugin`）。
6. 配置全局样式：`src/shared/styles/main.css` 中 `@import "tailwindcss";` 与 `@import "@nuxt/ui";`，并在入口引入。
7. 创建最小路由与首页占位：`/` 渲染占位页，页面内放一个 Nuxt UI 组件（如 `UButton`）用于验证组件链路。
8. 创建 `src/` 目录骨架（见上文结构）。
9. 配置 TypeScript strict 与 ESLint flat config（当前 Vue/TS 兼容配置）。
10. 创建 `.env.example`、`.gitignore`。
11. 配置 Vitest 基线（一个冒烟测试，验证占位组件可挂载）。
12. 配置 `package.json` scripts：`dev / build / lint / typecheck / test / check`，并在 `packageManager` 固定 pnpm 版本。

## 关键陷阱与注意事项

- Nuxt UI v4 的 Vue 集成必须使用官方当前文档方式（`@nuxt/ui/vite` 插件 + `@nuxt/ui/vue-plugin`），不要复制旧 Nuxt UI v2/v3 教程，不要使用已归档的 v3 starter。
- Tailwind CSS v4 采用 CSS-first 配置，不要在 `tailwind.config.js` 里做 v3 式配置。
- 本任务不做主题定制与 token 落地（那是 FE-002）；占位页只需证明技术链路通畅。
- 不添加任何 AGENTS.md 未批准的依赖；新增依赖必须先检查 `package.json` 并说明理由。
- 不要在本任务中开始任何首页设计或业务组件。
- 占位页文案使用简体中文（FrontendDesign.md §0.1）。
